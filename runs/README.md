# Runs Directory

Generated outputs from the cleaned pipeline are written here:

```text
runs/<run_name>/
  config_used.yaml
  dataset_validation.json
  validated_dataset.csv
  splits/
  models/
  predictions/
  metrics/
  pareto_fronts/
  figures/
  logs/
```

Run folders are ignored by Git. Keep only small, intentional examples under version control.
